# 모닝 브리핑을 루틴으로 거는 법

[claude.ai/code](https://claude.ai/code) 웹 UI에서 루틴을 만듭니다(컨테이너 안에선 루틴 생성 불가).

## 1. 루틴 만들기

1. claude.ai/code → **구름(cloud) 아이콘** → **Routine**(루틴) 생성.
2. **저장소/브랜치**: `dltjdwo0212pm/flow_ai-3-` · `claude/admiring-darwin-37twsn`.
3. **환경/커넥터**:
   - **Flow MCP 커넥터 ON** (게시: `flow_create_post`). MCP는 Anthropic 경유라 `api.flow.team` egress 추가 불필요.
   - **웹 검색(WebSearch) 사용 가능**한 환경. (뉴스 수집에 필요)
4. **스케줄**: **평일(월~금) 09:00 (KST)**. 타임존을 한국으로. (가능하면 주말 제외로 설정 — 안 되면 매일로 두어도 프롬프트 가드가 토·일 게시를 막습니다.)
5. **종료 설정 (중요)**: 트라이얼이라 **2026-06-26(다음 주 금)까지만**.
   - 루틴에 종료일 설정이 있으면 `2026-06-26`로 지정.
   - 없으면 다음 주가 지난 뒤 **루틴을 끄거나 삭제**하세요. (프롬프트에도 날짜·주말 가드가 있어 그 이후엔 게시하지 않지만, 루틴 자체는 수동으로 꺼야 호출이 멈춥니다.)

## 2. 루틴 프롬프트

프롬프트 칸에 한 줄만(파일 수정 시 자동 반영):

```
이 저장소의 agents/morning-briefing/ROUTINE_PROMPT.md 를 읽고, 적힌 절차대로
오늘자 모닝 브리핑을 작성해 PM2팀 방(2879897)에 게시해줘.
```

> 또는 `ROUTINE_PROMPT.md` 본문 전체를 붙여넣어도 됩니다.

## 3. 조정 포인트

| 바꾸고 싶은 것 | 어디서 |

| 게시 시간/요일 | 루틴 스케줄 |
| 트라이얼 종료일 | 루틴 종료 설정 + `ROUTINE_PROMPT.md` 0번 가드 날짜 |
| 뉴스 영역/건수 | `ROUTINE_PROMPT.md` 1번 |
| 글 톤·섹션·제목형식 | `ROUTINE_PROMPT.md` 3번 |
| 게시 대상 프로젝트 | `ROUTINE_PROMPT.md`의 `projectId` |
