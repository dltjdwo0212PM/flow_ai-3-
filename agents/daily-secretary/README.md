# 🤖 데일리 비서 (Daily Secretary)

이성재(robby95 · 상품기획실 PM2팀)를 위한 **나만의 Flow 에이전트**.
매일 아침 Flow(flow.team)를 훑어 "오늘 뭐부터 챙겨야 하는지"를 한 화면으로 정리한다.

- **형태**: Claude Code 루틴(스케줄 자동 실행)
- **실행 위치**: Claude + Flow MCP 커넥터 (별도 API 키·egress 설정 불필요)
- **역할**: ① 데일리 비서 브리핑 ② 회의 준비 지원
- **안전**: 기본 읽기 전용. 쓰기(멘션 답글·마감 변경·업무 생성)는 항상 확인 후.

## 사용하는 Flow MCP 도구

- `flow_get_my_worklist` — 마감 지남/임박 + 나를 멘션
- `flow_suggest_my_focus` — "오늘 이거부터" 점수·이유 픽
- `flow_query_events` (+ 폴백 `flow_search_event` / `flow_list_calendars`) — 오늘 일정
- `flow_search` — 회의 제목으로 관련 글 찾기 (회의 준비)
