# 🧭 intake-clarifier (기획요청 되묻기 봇)

Flow 엔터프라이즈·공공 **기획요청**을 시니어 IT 서비스 기획자 관점으로 읽고, 개발 착수가
가능한 수준으로 끌어올리는 **"되묻기 질문"을 댓글로 자동 게시**한다.

- **형태**: Claude Code **서브에이전트** — 정의는 [`.claude/agents/intake-clarifier.md`](../../.claude/agents/intake-clarifier.md)
- **연동**: `flow_get_post`·`flow_list_project_items`·`flow_get_project`·`flow_list_project_participants`·`flow_search` + **`flow_create_comment`(게시)**
- **대상**: `[PM] 엔터 기획 요청` (`1551252`) — **2026-06-18 이후 새 글만**
- **분석**: 5축 갭분석(근본니즈·범위경계·사용자/시나리오·기존기능재활용·제약/성공기준)
- **질문**: 닫힌 질문 **3개(최대 5)**, 우선순위순, 추측 단정 금지

## 동작 (자동 게시)

```
새 기획요청(1551252) → (루틴이 매시간 실행) → 본문 5축 분석
   → [내부 분석] 실행 로그에 남김(성재만, 비게시)
   → [댓글] 🧭 마커 + 닫힌 질문 3개를 flow_create_comment로 게시
```

### "새 글에만" 보장 (2겹 가드)
1. **기준일**: `등록일 ≥ 2026-06-18` → 기존 글(현재 최신도 5/28)은 전부 제외.
2. **중복 마커**: 댓글 첫 줄 `🧭 [기획 사전 확인]` 이 있으면 그 글은 건너뜀(한 글당 1회).

> ⚠️ Flow 댓글은 **삭제 불가**. 자동 게시 특성상 한 번 달리면 못 지우니, 켠 첫 1~2일은 결과를 확인하세요.

## 쓰는 법

**수동(즉석)** — 이 repo 기반 세션에서:
```
@intake-clarifier 1551252 새 글에 사전 질문 댓글 달아줘
@intake-clarifier 이 글(postId 78385395) 처리해줘
```

**자동(무인)** — 루틴으로: [`SETUP.md`](./SETUP.md) 참고. 평일 매시간 폴링으로 새 글에 자동 게시.

## 게시되는 댓글 예시 (스타일 참고)

> 요청: "[금융감독원] 쪽지·대화·알림봇 삭제 기능"

```
🧭 [기획 사전 확인] 요청 주셔서 감사합니다. 정확한 설계를 위해 아래 확인 부탁드립니다.

1. 쪽지·대화 삭제는 (A) 발신·수신 양쪽에서 제거 + '삭제됨' 표기, (B) 발신자 화면에서만 제거 중 어느 쪽일까요?
2. 서버 마스킹 시 원문은 (A) 완전 파기, (B) 보존 후 마스킹 중 무엇일까요? 금융감독원 보존의무와 충돌이 없는지도 확인이 필요합니다.
3. 적용 범위는 (A) 신규 메시지부터, (B) 기존 누적 메시지 소급 포함 중 무엇일까요? (소급이면 마이그레이션 범위 산정이 필요합니다.)
```

`[내부 분석]`(리스크·공수·기존기능 대체 메모)은 실행 세션에만 남고 **게시되지 않습니다.**
